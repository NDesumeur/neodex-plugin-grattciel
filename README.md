# Gratte-ciel

Empile les étages d'un gratte-ciel : chaque étage glisse, lâche-le au bon moment. Ce qui dépasse tombe. Monte jusqu'aux étoiles.

Clic ou espace : poser l'étage qui glisse. La partie qui dépasse est coupée. Un étage posé pile dessus garde sa largeur ; trois à la suite élargissent la tour. Le ciel change avec la hauteur, jusqu'à l'espace.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Gratte-ciel → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
